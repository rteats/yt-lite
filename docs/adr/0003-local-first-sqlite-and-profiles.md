# Local-first SQLite state with local profiles

yt-lite will store user data locally in SQLite and provide import/export, with an option to add synchronization later rather than requiring accounts or servers now. Multiple local profiles will support independent local subscriptions and feeds. This favors offline availability, privacy, and low idle overhead over built-in cross-device synchronization.

**Open boundary:** Whether history, playlists, downloads, and caches are shared between profiles or isolated per profile still needs an explicit decision.
