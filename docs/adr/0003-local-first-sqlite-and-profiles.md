# Local-first SQLite state with local profiles

yt-lite will store user data locally in SQLite and provide import/export, with an option to add synchronization later rather than requiring accounts or servers now. Multiple local profiles will isolate subscriptions, history, playlists, playback progress, persistent playback queues, feed preferences, and offline-library visibility. This favors offline availability, privacy, and low idle overhead over built-in cross-device synchronization.

**Consequences:** A profile's library entries are private to that profile, while underlying downloaded media can be shared without duplication. Profile switching saves the previous profile's playback position and stops playback before loading the next profile. A temporary private session does not record history, progress, or local recommendation signals. Permanent actions taken in private mode, such as subscription, playlist changes, or downloads, require explicit confirmation that they will be saved to the active profile. Unavailable videos remain in local history and playlists, with their existing metadata retained and an unavailable indication; local offline copies can still play. No login is necessary.

Before potentially destructive database migrations, create a recoverable backup. Allow manual backup and restore, and validate imported data. Subscription feeds refresh when opened, with cache freshness, rate limits, and user-configurable refresh intervals instead of continuous background polling.
