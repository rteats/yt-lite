# SponsorBlock and Return YouTube Dislike enabled by default

yt-lite will enable SponsorBlock and Return YouTube Dislike by default, with independently configurable disable controls, while keeping optional third-party extraction proxies disabled until chosen. This prioritizes the requested video experience but deliberately allows outbound requests to those integration services.

**Consequences:** The app must clearly disclose integration endpoints and request behavior, and local-only diagnostics must not be confused with absence of network access. Dislike numbers are estimates, not official counts.
