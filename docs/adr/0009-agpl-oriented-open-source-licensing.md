# AGPL-oriented open-source licensing

yt-lite will pursue an AGPLv3-oriented licensing strategy to accommodate an open-source desktop client and potential reuse of compatible copyleft code from related projects. This prioritizes lawful reuse and reciprocal source availability over permissive downstream relicensing.

**Consequences:** This is a license direction, not a blanket permission to copy code. Each source, port, bundled binary, and library must be checked for license-version compatibility, attribution, build obligations, and distribution requirements. Final repository licensing and third-party notices must be resolved before shipping copied or redistributed components.
